Bluetooth (Web Serial) diagnostics

Logs every Web Serial event and the exact error of each step, to find out how to recover after the Bluetooth link drops. / Bluetooth のリンクが切れた後に復帰する方法を探すため、Web Serial のイベントと各操作のエラーをそのまま記録します。

  1. Choose port → Open → Status (works?) / ポートを選んで開き、状態を読む
  2. Turn the printer off, wait 10 s, turn it on / プリンターの電源を切り、10 秒待って入れる
  3. Try, in order: Status → Open → Close then Open → Re-pick from getPorts → Choose port again / 上から順に試す
  4. Copy the log / ログをコピーして共有
